# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Do not disclose it publicly** in public issues or discussions.
2. Please report security issues directly via GitHub Security Advisories or by contacting the repository maintainer privately.
3. Include detailed steps to reproduce the issue, the affected hardware environment, and firmware build version.
4. You will receive an acknowledgment within 48 hours, followed by updates on the fix and coordinated disclosure.
